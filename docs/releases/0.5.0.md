# PyTradeKit 0.5.0

**Status:** Release candidate - blocked pending complete real Alpaca PAPER qualification.

## Scope

PyTradeKit 0.5.0 adds the first durable PAPER trading runtime:

```text
PostgreSQL persistence
UnitOfWork
Inbox / Outbox
Alpaca PAPER runtime configuration
Alpaca anti-corruption layer
safe execution adapter
market data and portfolio snapshots
startup/restart reconciliation
private trade_updates processing
production qualification shell
```

## Safety model

```text
PAPER only
no LIVE fallback
single-attempt economic writes
UNCERTAIN instead of blind retry
client_order_id recovery
no synthetic fills
no silent position repair
TRADING_READY only after reconciliation
transactional Inbox / OMS / Portfolio / Outbox
```
