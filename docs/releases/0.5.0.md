# PyTradeKit 0.5.0 - Persistence + Alpaca PAPER

**Status:** Released after deterministic and real Alpaca PAPER qualification.

## Scope

PyTradeKit 0.5.0 introduces the first durable provider-connected PAPER runtime:

~~~text
PostgreSQL persistence
UnitOfWork
Inbox / Outbox
ProcessedFillRegistry
Provider Discovery
Alpaca PAPER RuntimeProfile
Alpaca Anti-Corruption Layer
Alpaca Execution Adapter
IEX market data
Account and position snapshots
private trade_updates
startup/restart reconciliation
TradingReadinessReport
admission control
graceful shutdown
fault qualification
real PAPER release gate
~~~

## Safety model

~~~text
PAPER only
no LIVE fallback
single-attempt economic writes
UNCERTAIN instead of blind retry
client_order_id recovery
provider IDs remain external evidence
no synthetic fills
no silent position repair
TRADING_READY only after convergence checks
transactional Inbox / OMS / Portfolio / Outbox
~~~
