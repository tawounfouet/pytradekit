# PyTradeKit 0.8.0a2 - Compliance Test Kit & Evidence Model

**Status:** Alpha milestone - LOT-02.

PyTradeKit 0.8.0a2 makes broker qualification executable, repeatable and evidence-backed without introducing a second broker implementation.

## Added

- ComplianceCriticality and ComplianceEvidenceType.
- ComplianceRequirement with capability, target level, applicability and evidence requirements.
- ComplianceScenario with explicit preconditions, expected result, failure semantics, cleanup and requirement linkage.
- ComplianceStatus with PASS, FAIL, BLOCKED and NOT_APPLICABLE.
- ComplianceResult with provider/environment, timestamps, reason and retained evidence references.
- ComplianceEvidence linked to exact commit, adapter version, SDK version, provider, environment, contract and scenario.
- EvidenceSanitizer for secret-safe JSON-like qualification payloads.
- ComplianceObservation and ComplianceScenarioExecutor.
- ComplianceHarness shared across ProviderFixture implementations.
- ComplianceRun deterministic artifact containing report, evidence and registry.
- ComplianceReport and ComplianceReportGenerator.
- CertifiedCapability with capability-specific certification level and constraints.
- CertificationRegistry as an immutable generated static registry.
- StaleEvidencePolicy with adapter, SDK, contract, commit and age invalidation semantics.
- ProviderCapabilityManifest schema candidate version 1.0-rc1.
- Broker certification guide.
- FF-057 through FF-059.

## Qualification semantics

- Manifest support remains distinct from certification.
- BLOCKED is not collapsed into FAIL.
- FAIL requires observed behavior that violates a requirement.
- Cleanup failure blocks qualification.
- C3 requirements require PAPER evidence.
- The same ComplianceHarness can qualify multiple ProviderFixture implementations.
- Critical failures cannot be waived into C3.
- Changed adapter or SDK identity makes prior evidence stale.
- Final qualification artifacts are secret-scanned.
- Raw provider SDK objects are not accepted as evidence payloads.
