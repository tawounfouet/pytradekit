**Status:** Release candidate milestone - LOT-07.

- env://, file://, and external:// provider support.
- RoutedSecrets and file-root confinement.
- RuntimeSecurityConfig with lifecycle, database timeout, pool, and TLS controls.
- Approved Alpaca PAPER endpoint validation.
- PostgreSQL connection hardening.
- Bounded startup and bounded telemetry shutdown flush.
- Deployment preflight with fail-closed dependency checks.
- Read-only /health/live and /health/ready surface.
- Unprivileged read-only Docker and Compose PAPER profile.
- Alembic SecretRef database resolution and migration-before-runtime entrypoint.
- Provider outage, rotation, and startup timeout runbooks.
- FF-047 proving 0.7 cannot enable LIVE.
