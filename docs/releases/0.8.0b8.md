# PyTradeKit 0.8.0b8 - IBKR PAPER Evidence Certification Harness

**Status:** Beta candidate - real PAPER evidence not yet retained.

0.8.0b8 adds the evidence and certification layer required to convert deterministic IBKR support into capability-specific real PAPER certification.

## Added

- IBKRPaperEvidenceBundle;
- IBKRPaperEvidenceProvenance;
- explicit evidence schema version 1;
- qualified-commit and self-verifying canonical SHA-256 provenance;
- PAPER workflow run and exact deterministic CI run provenance;
- capability-specific C3 claims;
- deterministic C2 compliance certification for all declared IBKR capabilities;
- retained PAPER evidence replay through the common ComplianceHarness;
- controlled real IBKR PAPER probe through IBKRExecutionAdapter;
- Actions-only evidence normalizer deriving C3 claims from observed proofs;
- manual self-hosted IBKR PAPER certification workflow;
- release-safe rule that no retained evidence means no C3.

## Current certification status

Standard CI certifies deterministic C2 only.

No real IBKR PAPER artifact is fabricated or embedded by this release. A local diagnostic report cannot promote C3. C3 normalization requires the dedicated GitHub Actions workflow, a successful CI run on the exact commit and a content-valid retained bundle.

TRADING_READY remains closed.

LIVE remains unavailable.
