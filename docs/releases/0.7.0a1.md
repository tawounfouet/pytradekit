# PyTradeKit 0.7.0a1 - Identity, Actors & RBAC

**Status:** Alpha milestone - LOT-01.

PyTradeKit 0.7.0a1 introduces provider-neutral identity and role foundations.

Implemented:

- ActorId, ActorType, Actor, RoleId, Role, Permission, and PermissionSet.
- AuthenticatedPrincipal and PrincipalContext.
- Typed environment, account, and operation scopes.
- Time-bound RoleAssignment with deterministic expiry.
- In-memory and PostgreSQL security repositories.
- Alembic security schema migration.
- PostgreSQL round-trip and revocation tests.
- FF-036 provider independence for security.domain.
- SQLAlchemy independence for security.domain.

LIVE remains unavailable.
