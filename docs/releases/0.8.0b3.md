**Status:** Beta milestone in progress - LOT-06.

0.8.0b3 adds provider-neutral startup reconciliation over synchronized IBKR PAPER read-side state.

- IBKRBrokerSnapshotPort;
- synchronized account, portfolio, trade and fill normalization;
- explicit conId instrument resolution;
- explicit provider order identity resolution;
- explicit account restriction evidence requirement;
- IBKRReadSideCoverageEvidence;
- PARTIAL snapshots when provider inventory completeness is unproven;
- external order and fill visibility without automatic adoption;
- IBKRStartupReconciliationGate;
- CONSISTENT/HIGH read-side qualification with economic writes still blocked;
- deterministic LOT-06.2 qualification artifact.

## Safety

0.8.0b3 does not call placeOrder or cancelOrder.

It does not claim real IBKR PAPER capability certification.

It does not expose LIVE.
