# PyTradeKit 0.8.0b5 - IBKR Order Session Sequencing

**Status:** Beta milestone in progress - LOT-06.

0.8.0b5 adds synchronized IBKR order ID reservation and callback correlation without enabling economic writes.

## Added

- IBKROrderSessionRuntime;
- IBKROrderSessionSequencer;
- IBKRCallbackCorrelationRouter;
- IBKROrderCorrelationRegistry;
- IBKROrderSessionReservation;
- explicit clientId plus orderId routing;
- canonical OrderId plus orderRef pre-write correlation;
- permId late binding;
- openOrder correlation;
- orderStatus correlation;
- order-scoped error discrimination;
- unknown callback non-adoption;
- deterministic LOT-06.4 qualification;
- safe real PAPER order-sequence probe.

## Safety

0.8.0b5 does not call placeOrder.

0.8.0b5 does not call cancelOrder.

An allocated orderId is not evidence that an economic write occurred.

No real IBKR PAPER execution capability certification is claimed.

TRADING_READY remains unavailable for IBKR.

LIVE remains unavailable.
