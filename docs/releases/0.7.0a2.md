# PyTradeKit 0.7.0a2 - Authorization & Scoped Permissions

**Status:** Alpha milestone - LOT-02.

PyTradeKit 0.7.0a2 completes scoped authorization on top of LOT-01.

Implemented:

- AuthorizationDecision with stable reason codes.
- AuthorizationPolicy and AuthorizationService.
- PrincipalProvider and authorization audit boundaries.
- AuthorizeAction fail-closed application use case.
- Orders-owned authorization gate.
- SUBMIT_ORDER and CANCEL_ORDER authorization integration.
- Negative tests for missing permission, disabled actor, expired assignment, and scope mismatch.
- Property qualification for no-permission denial.
- E2E proof that denied order actions never reach ExecutionPort.

Authorization remains separate from Safety. LOT-03 introduces SafetyState, SafetyDecision, and SafetyGate.

LIVE remains unavailable.
