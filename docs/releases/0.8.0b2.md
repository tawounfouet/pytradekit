# PyTradeKit 0.8.0b2 - IBKR PAPER Runtime Integration

**Status:** Beta milestone in progress - LOT-06.

0.8.0b2 begins provider-backed IBKR PAPER runtime integration on top of the completed SDK-free Anti-Corruption Layer.

## LOT-06.1 - Transport Selection & PAPER Connection Runtime

Added:

- optional ibkr package extra;
- exact ib_async==2.1.0 transport pin;
- provider-local IBKRPaperRuntimeProfile;
- loopback-only IB Gateway connection policy;
- IB Gateway PAPER port 4002 hard lock;
- non-zero client ID policy to avoid automatic manual-order binding;
- IBAsyncPaperTransport;
- synchronized socket and protocol readiness checks;
- expected managed-account verification;
- sanitized StartupReadinessReport;
- safe real PAPER connection probe with no economic write;
- dedicated LOT-06.1 architecture, public-contract, unit and qualification gates.

The core RuntimeProfile remains Alpaca-only and unchanged.

The official ibapi package is still not bundled.

A successful LOT-06.1 connection means only:

~~~text
READY_FOR_STARTUP
~~~

It does not mean:

~~~text
TRADING_READY
C3 PAPER QUALIFIED
~~~
