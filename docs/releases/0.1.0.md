# PyTradeKit 0.1.0 - Domain Foundations

## Release message

PyTradeKit 0.1 provides the domain foundations only. It does not yet connect to brokers or execute trades.

## Included

- financial Value Objects: Currency, Money, Price, Quantity, Percentage
- typed UUID identifiers
- CorrelationId and CausationId
- DomainEvent primitives
- canonical Instrument identity
- AssetClass
- ContractSpecification
- InstrumentMapping
- ClockPort and SystemClock
- FakeClock
- InstrumentBuilder
- Hypothesis finance strategies
- architecture fitness functions
- public import contract tests
- wheel and sdist qualification
- clean wheel installation smoke test
- SHA-256 calculation for release artifacts

## Architectural guarantees

The qualified foundation enforces:

- Decimal financial semantics
- provider-independent canonical identity
- explicit UTC-aware time
- no hidden system clock in Domain
- minimal Shared Kernel
- no infrastructure framework in Domain
- controlled root package exports
- mechanically enforced dependency boundaries

## Explicit limitations

0.1.0 does not include:

- OMS
- broker connectivity
- database persistence
- backtest engine
- HTTP API
- audit persistence
- runtime profiles
